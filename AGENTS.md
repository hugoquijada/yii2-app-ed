## Aplicación de las guías

1. Para cualquier cambio, revisa las convenciones de código y arquitectura, el procedimiento de desarrollo de funcionalidades y la lista de revisión.
2. Para cambios de modelos, controladores, módulos o correo, consulta también la guía específica correspondiente.
3. Si una necesidad no está cubierta o requiere apartarse de un estándar, revisa la guía de excepciones y deja explícita la justificación; no inventes una convención nueva.
4. Respeta el alcance de la aplicación: el dominio y la configuración propia pertenecen aquí; la infraestructura reutilizable debe evaluarse para `yii2-ed` en lugar de copiarse a esta aplicación.
